## 🎯 Why Code Manager?

Code Manager was built to easily manage short codes, terminal commands, configurations, and reusable snippets—things that usually get lost between various projects, files, and scattered notes. 

The main goal of this project is to keep all your code snippets organized in a fast and simple environment featuring folder structures, search, filtering, syntax highlighting, and backups, all **without the need for a server or an internet connection**.

## ✨ Features

- 📁 **Nested Folders:** Organize your snippets hierarchically.
- 💻 **Syntax Highlighting:** Beautiful code formatting using Prism.js.
- 🔎 **Fast Search & Filter:** Quickly find exactly what you need.
- 🌙 **Theme Support:** Switch between Dark and Light modes.
- 🌍 **Multilingual:** Supports English, Persian, and Arabic.
- 💾 **Backup & Restore:** Easily export and import your data via JSON.
- 📋 **Quick Copy:** Copy snippets to your clipboard with a single click.
- ⚡️ **Completely Offline:** Your data stays locally on your device.
- 🖥 **Direct Execution:** Just open the HTML file, no setup required.

## 🚀 Usage

Running this application is incredibly simple. There is absolutely no need for a Server, Node.js, Python, or an internet connection.

Just open the following file in your web browser:
```text
index.html
```
