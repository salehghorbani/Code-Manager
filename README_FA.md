## 🎯 چرا Code Manager ساخته شد؟

نرم‌افزار Code Manager برای مدیریت راحت کدهای کوتاه، دستورات، تنظیمات و قطعه‌کدهای قابل استفاده مجدد ساخته شده است؛ چیزهایی که معمولاً بین پروژه‌ها، فایل‌ها و یادداشت‌های مختلف گم می‌شوند.

هدف این پروژه آن است که تمام این کدها را با قابلیت‌هایی نظیر پوشه‌بندی، جستجو، فیلتر، هایلایت سینتکس و بکاپ در یک محیط ساده و سریع نگه دارد؛ **بدون نیاز به سرور یا اینترنت**.

## ✨ امکانات

- 📁 **پوشه‌های تو در تو:** مرتب‌سازی قطعه‌کدها به صورت ساختار درختی و منظم.
- 💻 **Syntax Highlighting:** نمایش رنگی و خوانای کدها.
- 🔎 **جستجو و فیلتر سریع:** پیدا کردن فوری کدهای مورد نیاز.
- 🌙 **حالت تاریک و روشن:** پشتیبانی از تم‌های ظاهری مختلف.
- 🌍 **چندزبانه:** پشتیبانی از زبان‌های فارسی، انگلیسی و عربی.
- 💾 **بکاپ و Import با JSON:** خروجی گرفتن از اطلاعات و بازیابی آسان آن‌ها.
- 📋 **کپی سریع کد:** کپی کردن کدها در کلیپ‌بورد تنها با یک کلیک.
- ⚡️ **کاملاً آفلاین:** بدون نیاز به اینترنت و حفظ حریم خصوصی داده‌ها.
- 🖥 **اجرای مستقیم:** اجرا تنها با باز کردن فایل `index.html`.
